# Estia — frontend

React 19 + TypeScript single-page app (Vite, Tailwind CSS, TanStack Table, Recharts).
See the [project README](../README.md) for the full picture.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to the Flask API on :5050
npm run lint     # oxlint
npm run build    # type-check + production build in dist/, served by Flask in production
```
